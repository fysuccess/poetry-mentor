# 互动赏析网页生成

将古诗词赏析结果渲染为**单文件 HTML 互动页面**，交付 .html 文件供用户浏览器打开、分享、导出图片。

## 核心规则（铁律）

1. **单文件全内联**：CSS、JS、SVG 图标全部内联在一个 .html 里；**绝不引用外部框架/CDN/字体/图表库/图片**；字体用系统字体栈 `-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`
2. **多主题换肤**：内置「宣纸（浅色）」与「水墨（深色）」两套主题，通过 `html[data-theme="ink"]` 切换 CSS 变量；页面悬浮栏提供主题切换按钮；导出海报 Canvas 颜色跟随当前主题
   - 宣纸主题：米色底 `#faf6ec` + 墨黑 `#2b2b2b` + 朱红 `#a63d2f` + 金铜 `#b8860b`
   - 水墨主题：墨黑底 `#1c1a15` + 宣纸白 `#e8e2d2` + 亮朱红 `#d96a5a` + 金 `#d9b45b`
3. **年龄段 Tab**：学龄前 / 小学低年级 / 小学高年级 / 初中 / 高中 / 成人 六个 Tab，点击切换对应赏析内容（不刷新页面）
4. **逐句朗读**：用浏览器原生 `speechSynthesis`（Web Speech API）朗读诗句，**无任何外部依赖**；点击诗句行即朗读
5. **生僻字注音**：数据区 `annotations: {字: 拼音}` 定义注音映射，渲染时自动用 `<ruby>字<rt>拼音</rt></ruby>` 包裹；悬浮栏「注音」按钮一键显示/隐藏拼音
6. **生僻字点击查释义**：数据区 `dict: {词: 释义}` 定义字词释义（长词优先匹配），命中词渲染为朱红下划线可点击热词，点击弹出释义浮层（长词自动朗读）；热词点击不会误触诗句朗读
7. **诗词填空小游戏**：数据区 `quiz: [{text, answer, options[], hint}]` 定义挖空题（`____` 为空格）；答对变绿+自动朗读整句，答错抖动提示，全部答对显示庆祝；「再玩一次」重置
8. **诗词接龙 AI 对战**：数据区 `dragon: {字: [诗句, ...]}` 提供 AI 出句池（按字分组）；玩法——选字 → AI 先出句 → 玩家输入含该字的诗句（校验：必须含字、≥4字、不重复）→ AI 接龙 → 任一方无句可接即输；内置「认输」按钮，状态栏显示对局进度
9. **诗词消消乐**：从原文自动生成（无需数据字段）——每句去掉标点后打乱字块，玩家按正确顺序点击拼回原句；逐字判定（当前位正确变绿，错误抖动），拼完自动朗读整句，全部拼完庆祝；「再玩一次」重置
10. **意象雷达图**：数据区 `radar: {labels[], values[], note}`（5 维 0-100）→ 用**内联 SVG 手绘**六边形雷达图（4 层网格 + 数据多边形 + 顶点圆点 + 维度标签 + 中心均值），颜色跟随主题；右侧图例展示各维度分值
11. **竖排古籍版式**：悬浮栏「版式」按钮在「横排现代 ⇄ 竖排古籍」间切换；竖排用 `writing-mode: vertical-rl` + `text-orientation: upright`，诗句从右向左排，名句同步竖排，朗读/注音/释义功能竖排下依然可用
12. **四选一导出**：点击「导出」弹出选择浮层——①**完整学习单 PNG**（`exportFullPNG`：Canvas 动态高度绘制，含 标题区+原文+6 段分龄解读+名句赏析+雷达图（`drawRadarCanvas` 手绘）+学习方案+品牌页脚，命名 `{诗名}_{作者}_学习单.png`）②**PDF 文档**（`exportPDF`：临时展开全部年龄段 + `window.print()` 打印对话框选「另存为 PDF」，`@media print` 样式隐藏导航/悬浮栏/游戏模块只留内容）③横排现代海报 PNG（1080×1350 跟随主题）④竖排古籍海报 PNG（1080×1440 仿宣纸+竖排+印章）；均零依赖实现
13. **品牌页脚**：页面底部与海报落款统一使用「古诗词趣味工坊 · 让读诗成趣」+ 一句话简介「海量古典诗词，五维赏析与分龄教学」，不显示数据来源细节（诗泉 API 仅作内部引用，不对外展示）
14. **品牌徽标**：页面使用古风印章式徽标（宣纸圆底 + 金铜弯月 + 朱红「诗」字 + 「趣」小方印），顶栏导航与页脚各一处内联 SVG；导出海报用 Canvas 版徽标（`drawBrandMark`），横排海报右上角、竖排古籍海报左上角 + 朱红「詩」印章
15. **PC/手机双适配**：窄屏单列堆叠、按钮 ≥44px、输入框字号 ≥16px、适配 iPhone 底部安全区 `padding-bottom: env(safe-area-inset-bottom)`；窄屏（<480px）悬浮栏按钮隐藏文字只显示图标
16. 页面头部注释标明 `<!-- 本页面由「古诗词趣味工坊」专家生成 -->`

## 页面结构

```
1. 顶部导航条：页标题（如「《静夜思》赏析」）+ 朝代/作者/体裁徽章
2. 主视觉卡片：诗名（大号）→ 正文（逐句，点击朗读）→ 一句总评
3. 年龄段 Tab 栏（6 段）→ 内容区（一句话读懂 / 画面细读 / 字词妙处 / 情感主旨 / 学习建议）
4. 名句卡片：朱红大字名句 + 点评
5. 学习方案卡片：背诵技巧 / 亲子互动 / 延伸阅读
6. 底部：数据来源「诗泉 API」+ 生成说明
7. 悬浮操作栏（移动端底部固定）：「🔊 朗读全文」「⬇️ 导出图片」「📋 复制原文」
```

## 数据填充

页面所需数据（由主 agent 在对话中产出后填入模板）：

| 数据 | 说明 |
|------|------|
| `poem.title` | 诗名（如 静夜思） |
| `poem.author` | 作者名（如 李白） |
| `poem.dynasty` | 朝代（如 唐） |
| `poem.type` | 体裁（如 五言绝句） |
| `poem.content[]` | 正文数组，每行一句 |
| `poem.annotations{}` | 生僻字注音映射 `{字: 拼音}`（可选） |
| `poem.dict{}` | 字词释义库 `{词: 释义}`，点击热词弹释义（可选） |
| `poem.quiz[]` | 填空题目 `{text, answer, options[], hint}`，text 用 `____` 标记空格（可选） |
| `poem.dragon{}` | 接龙出句池 `{字: [含该字的诗句, ...]}`，每字 8-12 句（可选，缺省隐藏接龙） |
| `poem.radar{}` | 意象雷达图 `{labels[5], values[5], note}`，5 维 0-100（可选，缺省隐藏雷达图） |
| `poem.summary` | 一句话总评 |
| `ages[]` | 6 个年龄段 × {一句话读懂, 画面细读, 字词妙处, 情感主旨, 学习建议} |
| `famousLines[]` | 名句数组 × {line, comment} |
| `tips[]` | 学习方案（背诵技巧/互动问题/延伸阅读） |

## 使用方法

1. 复制 `templates/poem-page.html` 为底稿
2. 用诗词数据替换模板中的 `__DATA__`（一个 JSON 对象字面量，作为页面数据源）
3. 检查：所有文案为简体中文、无外部链接、无 emoji 图标（用内联 SVG）
4. 交付：将生成的 .html 写入工作目录并告知用户文件路径；用户可用浏览器打开、手机也能直接打开
