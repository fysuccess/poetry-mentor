# 互动赏析页设计规范

> 供生成赏析网页时参考，保证视觉统一、交互可靠。v4：新增消消乐 / 意象雷达图 / 竖排古籍海报导出。

## 一、双主题配色

所有颜色走 CSS 变量（`:root` 宣纸 / `html[data-theme="ink"]` 水墨），页面与导出海报同步切换。

### 宣纸主题（默认，浅色）

| 角色 | 色值 | 用途 |
|------|------|------|
| 宣纸底 | `#faf6ec` | 页面背景 |
| 深纸底 | `#f3ecdb` | 渐变末端 |
| 墨黑 | `#2b2b2b` | 正文 |
| 墨灰 | `#5a5446` / `#8a7f63` | 次要文字 |
| 朱红 | `#a63d2f` | 诗名、强调、Active Tab、名句 |
| 金铜 | `#b8860b` / `#d9b45b` | 装饰、徽章、分隔线、注音 rt |
| 卡片白 | `#fffdf6` | 卡片底色 |
| 边框线 | `#e5dcc3` | 卡片描边 |
| 答对 / 答错 | `#2e7d32` / `#c62828` | 填空反馈 |

### 水墨主题（深色，`data-theme="ink"`）

| 角色 | 色值 |
|------|------|
| 墨黑底 | `#1c1a15`（页面）`#242119`（卡片） |
| 宣纸白 | `#e8e2d2`（正文）`#b8b0a0`（次要） |
| 亮朱红 | `#d96a5a`（强调） |
| 金 | `#d9b45b`（装饰） |
| 边框 | `#3a3628` |
| 答对 / 答错 | `#81c784` / `#ef9a9a` |

> 切换逻辑：`applyTheme(t)` 设置 `document.documentElement.setAttribute("data-theme", ...)`；Active Tab 文字用 `#1c1a15` 保证对比度；悬浮栏用深色底 `#2b2b2b`，水墨主题用 `#0f0e0b`。

## 二、排版层级

1. 诗名：`clamp(32px, 7vw, 44px)` 超粗，朱红，字距 6px
2. 正文诗句：KaiTi 楷体 `clamp(19px, 4.6vw, 25px)`，字距 2px，每句一行按钮；注音开启时生僻字以 `<ruby>` 标注，rt 为金色小字（0.48em）
3. 章节标题：16px 朱红 + 内联 SVG 图标
4. 正文/列表：14.5-15px 墨黑

## 三、交互细节

| 功能 | 实现 |
|------|------|
| 主题切换 | 悬浮栏「主题」按钮，宣纸 ⇄ 水墨循环；`data-theme` 属性驱动 CSS 变量 |
| 注音开关 | `annotations {字:拼音}` + `<ruby>` 包裹；body 类 `no-ruby` 控制 rt 显隐；按钮高亮表示开启 |
| 释义浮层 | `dict {词:释义}` 长词优先替换为 `<span class="w">` 热词；点击弹浮层（词+释义），单字词自动朗读；浮层 fixed 定位自动避让屏幕边缘，点击其他区域关闭 |
| 竖排版式 | body 类 `vertical` + `writing-mode:vertical-rl`；诗句容器改为横向 flex 从右向左排，名句同步竖排；朗读/注音/释义兼容 |
| 年龄段切换 | 6 Tab 点击切换卡片，淡入 0.35s |
| 逐句朗读 | `speechSynthesis`，`lang=zh-CN`，优先中文语音；朗读中该句朱红高亮 |
| 朗读全文 | 正文逐句 + 名句拼接一次朗读 |
| 填空游戏 | 题目逐题展示，选项按钮点击作答：答对 → 空位变绿 + 朗读整句 + 计分；答错 → 空位抖动 + 提示；全对 → 庆祝 + 「再玩一次」重置 |
| 接龙对战 | 选字 → AI 从 `dragon[字]` 随机取未用句出题 → 玩家输入诗句（校验含字/≥4字/未用过，错误给红色判定气泡）→ AI 继续；AI 无句可接则玩家胜；「认输」按钮结束对局；对局状态显示在状态栏 |
| 消消乐 | 原文去标点 → 打乱字块 → 玩家按序点击；正确字变绿前进，错误字抖动提示；拼完整句自动朗读；全部完成显示庆祝 |
| 意象雷达图 | 内联 SVG 手绘六边形（`labels.length` 自适应边数），4 层网格 + 数据多边形（填充 `hexA(red,.22)`）+ 顶点圆点 + 标签 + 中心均值；配色取 CSS 变量（跟随主题） |
| 双风格导出 | 点击导出弹出选择浮层；横排 1080×1350 跟随主题；竖排古籍 1080×1440（仿宣纸 #f6efe0 + 双线框 + 右上竖排书名 + 正文从右往左逐列 + 左下名句 + 朱红「詩」印 + 落款） |
| 复制原文 | Clipboard API，降级 execCommand |

## 四、移动适配

- 窄屏单列堆叠，Tab 横向滚动（隐藏滚动条）
- 操作按钮 ≥44px；悬浮操作栏固定在底部居中，含 `env(safe-area-inset-bottom)`，**<480px 时按钮隐藏文字只留图标**，横向可滚动
- 无 `type="number"` 输入场景，无需数字键盘处理

## 五、铁律复核

- ✅ 单文件 HTML，CSS/JS/SVG 全内联
- ✅ 无任何 CDN / 外部字体 / 外部图片
- ✅ 图标全部内联 SVG，无 emoji（填空完成庆祝的 ⭐ 为 CSS 装饰文字，非功能图标）
- ✅ 导出图片用原生 Canvas，不依赖 html2canvas
- ✅ 朗读用 Web Speech API（浏览器原生）

## 六、数据注入方式

模板内 `var DATA = {...}` 为唯一数据源，主 agent 生成页面时整体替换该对象（JSON 结构：title/author/dynasty/type/content[]/annotations{}/dict{}/quiz[]/dragon{}/summary/ages[6]/famous[]/tips[]），其余渲染代码无需改动。`annotations`/`dict`/`quiz`/`dragon` 缺省时自动跳过对应模块。

## 七、接龙库补充建议

`dragon` 出句池按「字」分组，每字建议 8-12 句经典诗句（含字即可，无需完整诗）；常用飞花令字：月、春、花、山、水、风、雪、雨、云、夜、人、酒。专家生成页面时可按当首诗词的主题字优先补充；诗句需为真实古诗，句内用中文标点。
